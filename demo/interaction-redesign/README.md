# VoidMaker 两级原型 · 七海主题

浏览器直接打开 [index.html](index.html)。[主题依据](../../docs/CHIAKI_UI_THEME.md)记录官方资料、文字精简与像素图集映射；[交互方案](../../docs/UI_HMI_REDESIGN.md)记录两级骨架与 HMI 规则。

- 上方切换陪伴／沉浸和模拟状态；「立绘／3D」切换两级共用的角色显示方式。原型默认进入一级常态，只显示角色与图标。
- 点击文字图标才展开上一版小对话卡；直接输入、转写编辑、最近回复与上下文功能均保留。关闭小卡回到常态，草稿保留。
- 转写为操作条左侧的深青卡片；回复为角色头侧的淡粉纯文字气泡，去掉名字与图标；颜色、形状和位置明确区分。窄屏保留左侧转写，回复移至头部上方。
- 转写卡可直接点击编辑，无需展开小卡；Enter 发送，Shift+Enter 换行，Esc 退出编辑焦点并保留修改。清空后发送禁用，可继续输入。
- 常用动作使用图标，鼠标悬停或键盘焦点显示短名称。
- 常态语音：麦克风 → 勾号结束 → 左侧卡片显示转写 → 箭头直接发送 → 单句回复；全程不展开卡片或二级。方块取消，编辑是可选项。回复结束 5 秒后气泡收回。
- 原地修改和常态发送转写会保留已有文字草稿与附加内容，只发送左侧卡片中的本次转写；主动展开小卡后才选择替换／追加／放弃。连续模式在主动开启后自动发送。
- 文字卡展开／收起以及两级切换均保留草稿、语音轮次和角色显示方式；返回一级时恢复原来的卡片开合状态。
- 回复期间点击停止或按 Esc，旧计时不会复活该轮。Esc 也可关闭辅助面板、收起二级。
- 卡带图标打开任务：开始 → 模拟审批 → 允许一次／拒绝 → 产物。
- 加号打开上下文预览；设置可以减少动效。

所有事件、审批和服务状态为预设模拟，不连接 Host、不调用模型、不录音、不播放音频、不读取桌面、不写项目文件。

## 本地素材

原型尝试读取 `.local/pixel.png`、`.local/portrait.png` 与 `.local/model-preview.png`。当前工作区用符号链接指向用户提供的图集和已有角色立绘，原图未修改。`model-preview.png` 是通过现有 `Character3D.qml` 独立渲染的透明静态预览，浏览器不运行实时 3D；页脚明确标注这一限制。缺少预览会显示提示，不以立绘冒充 3D。

`.local/` 被 Git 忽略，不能提交链接、资产或含角色素材的截图。其他机器可以点击底部「素材」选择图片：490 × 343 的图片识别为图集，其余作为立绘。素材只在当前页面内使用，不上传、不持久化个人路径。缺少素材时显示简单占位标记，主界面仍可操作。

图集通过 CSS 显示区域裁切；`sprite-atlas.json` 提供坐标与状态映射。图集映射属于 UI 设计，不声称是原游戏动画顺序。像素显示使用整数倍与最近邻，未生成或改绘像素素材。

## 预览与验证

直接打开 `index.html?mode=companion` 查看常态；`index.html?mode=companion&panel=open` 查看一级展开项；或 `index.html?mode=immersive&state=speaking`；追加 `&appearance=model` 选择 3D 静态预览。
本机预览保存在 `.local/previews/`，不随 Git 分发。

检查结果见主题文档第 7 节。
HTML/CSS 仅用于设计评审。正式应用继续使用 Quickshell，浏览器测试不证明 Wayland 点击穿透、焦点、真实录音或声画同步已经通过。
