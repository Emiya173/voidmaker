# VoidMaker 右侧侧栏原型

直接在浏览器打开 `index.html` 即可操作。页面使用预设回复，不连接 VoidMaker 后端，也不会调用麦克风或读取屏幕。
如需直接查看特定状态，可在地址后加 `?state=expanded`、`?state=permission` 或 `?state=bubble`。

原型演示：

- 第一级只有固定立绘与临时气泡；点击立绘或按 `Alt+P` 展开第二级侧栏，按 `Esc` 收起。
- 点击「播放回复示例」或在侧栏发送消息，观察气泡打字和自动消失。
- 气泡消失后点击原位置的「点击穿透测试区」，确认桌面能收到点击。
- 点击「查看权限提示」，试用三种处理按钮；「记事」页演示长内容的容器。

交互源码是 `app.ts`，仓库中的 `app.js` 已构建好，直接打开 HTML 无需安装依赖。修改源码后可用 Node.js 22 运行 `node build.mjs` 重新生成 JavaScript。

`portrait.svg` 是专门为这个原型绘制的占位图，不代表最终角色资产。
