# 两级陪伴界面

2026-09-29：正式入口为 `apps/shell/shell.qml`，已接入 TypeScript Host。设计依据见 [七海主题](CHIAKI_UI_THEME.md)。

## 使用

- 默认是角色与五个图标：文字、录音、发送转写／停止、任务、沉浸交流。点击文字才展开小卡；录音不会自动展开。
- 录音时显示状态与音量，麦克风变为勾号结束采集；方块取消当前对话。转写完成后，操作条左侧出现深青卡片。
- 点击转写正文直接编辑，箭头或 Enter 发送，Shift+Enter 换行，Esc 离开输入焦点。组合输入期间不处理发送键。清空仍可继续编辑，发送按钮禁用。
- 文字草稿与转写独立。直接发送转写不会发送原草稿或桌面附件；小卡内可选择替换、追加或放弃转写。放弃／合并完成后语音回到空闲，可继续修改设置或会话。
- 角色回复使用头侧淡粉气泡，仅正文；结束后保留约五秒。完整记录在小卡和沉浸页内，墨紫／深青区分角色与用户。阅读旧消息时不强制滚到底部。
- 沉浸页放大舞台，记录可以折叠。返回一级恢复小卡先前开合状态，不发送输入或停止当前轮次。
- 小卡或沉浸页的图片／立方体按钮切换立绘与真实 Qt Quick 3D 模型。使用现有角色包；没有配置模型时禁用模型入口。模型加载失败会提示并显示立绘，不使用像素角色替代。
- 卡带打开后台任务并高亮，再次点击收起；时钟、设置、桌面入口同样切换对应面板。预览里的「附加到文字草稿」只影响下一条文字消息。
- 循环箭头明确开启连续语音后才自动发送。已有草稿或附件时不能开启；连续采集期间新写入草稿会使该轮停在转写确认，并释放持续采集会话。
- 完全隐藏或停止会取消当前语音／回复；后台任务继续独立运行。Host 独立检查 logind 的活动／锁定状态，开始采集前检查一次，活动轮次约每秒检查一次；状态不可用或锁定时停止。此行为不依赖桌面观察开关。

## 更新与状态边界

IPC **v9** 引入 Host 草稿投影与 `composer_edit / composer_send / composer_attach / composer_resolve` 命令。Host 和 Quickshell 必须一起更新、重启；本轮进一步升级至 **v10**，加入常驻桌面授权语义，无数据库迁移。

草稿按会话保存在 Host 内存中。界面断线重连、辅助面板切换与两级切换保留草稿；**Host 重启后未发送草稿不保留**。编辑缓冲带请求标识，旧确认不覆盖新的输入；转写操作携带生成代数，取消后的旧编辑／发送被拒绝。只有用户消息写入数据库后，才清理对应且未再次编辑的草稿。

角色使用一个 `CharacterView` 和一个按需加载的 `Character3D`。层级切换只改变布局；切换到立绘才卸载模型。主题基础色板在 `Theme.qml`，尚未加入角色包自定义主题配置。

界面仍使用 `PanelWindow` 的右下 layer-shell 锚点、`ExclusionMode.Ignore`，不预留桌面工作区。输入区域只包含操作条、编辑卡和辅助面板，角色及透明留白不加入 mask；键盘采用按需焦点。相关 API 依据：[PanelWindow](https://quickshell.org/docs/v0.3.0/types/Quickshell/PanelWindow/)、[按需键盘焦点](https://quickshell.org/docs/v0.3.0/types/Quickshell.Wayland/WlrKeyboardFocus/)。

## 验证

- `pnpm check`、`pnpm build`。
- 隔离 PostgreSQL 的两个独立数据库分别运行领域／存储测试与真实 Host 崩溃恢复测试；Codex、录音和 HTTP 模型使用假服务。
- `VOIDMAKER_SHELL_SMOKE=1 pnpm test`：真实 Quickshell 加载、私有测试 socket、原生编辑与键盘事件，覆盖常态录音流程、空转写、直接发送、草稿／附件隔离、两级切换、历史滚动、托盘入口、未保存设置与重连。
- 独立 Xvfb + Mesa 中检查现有本地 3D 模型、立绘切换、两级布局与模型实例保持。图像保存在被 Git 忽略的目录，不分发角色资产。
- 原生 Wayland 的独立短时面板已成功加载输入 mask，并按所在输出从 760 × 720 展开至 1035 × 800；没有连接正式 Host。此检查只验证容器加载与尺寸变化。

本轮最终回归为 **140 项通过、14 项可选测试跳过**，包含两个临时数据库和 Quickshell；TypeScript、Biome 与构建通过。最终弹出菜单／设置提示调整另行通过界面回归。

本轮未启用真实麦克风、ASR/TTS 或在线 Codex。Wayland 下的鼠标穿透、输入法候选窗、多屏／分数缩放、实际锁屏设备释放及 GPU 性能仍需实机交互验收；离屏测试不证明这些项目已通过。

## 2026-09-29 人工验收修正

- 对话/工作/朗读使用独立 TOML 中的 Sol medium；主动观察使用 Luna high。
  独立引擎目录仅复用登录凭据，线程启动、恢复和每轮都显式传入模型与推理强度。
  对接依据：[App Server](https://learn.chatgpt.com/docs/app-server) 与
  [独立配置目录](https://learn.chatgpt.com/docs/config-file/config-advanced)。
- 操作条以角色区域中心对齐；一级辅助面板放左侧，沉浸模式替换右侧聊天区；窄屏上下分区。
  首屏不绘制内置占位脸；选择 3D 时等待真实资源，加载失败才回退立绘。
- 托盘通过 StatusNotifier 的多尺寸 ARGB 图标显示薄荷绿手柄与粉色游戏徽记，不依赖系统笑脸图标。
- 中文显示文本与日语朗读台词分开。模型按近期上下文选择已安装的参考音频 ID，未知 ID / 段数不符拒绝播放。
  角色设定作为内部背景，要求自然回应、不复述卡片、不反复介绍身份或表演风格。
- 桌面面板支持分别保存窗口、媒体和手动截图的常驻授权；主动开关重启后恢复。临时授权仍在重启时清除。
- 本机安装模型更新至 `motion-refinement-v1/qt-candidate-v5` 的独立副本（23 部件，骨骼动作），
  角色包增加四组本地语气参考；角色与素材均不纳入 Git。原配置有备份，角色版本映射保留原会话与记忆。

验证：`pnpm check`、构建、两套独立 PostgreSQL 库及真实离屏 QML/D-Bus 回归通过，149 项通过、13 项可选跳过。
真实 Sol 与 Luna 请求通过；Sol 将中文转换为日语并选择轻声参考，四种参考均完成真实 GPT-SoVITS WAV 合成。
真实模型的一级/沉浸/辅助面板和窄屏截图已检查。没有启用麦克风或外放，音色自然度与实体设备交互仍由人工验收。

## 表情、面板稳定性与发饰图标修正

- 陪伴画布固定为 940 × 720（受屏幕可用尺寸限制），展开文字卡和辅助面板不再改变窗口或角色的位置、大小。
  宽屏卡片放在立绘左侧并预留至少 18 px 间隔；窄屏卡片在立绘上方。图片异步加载时保留上一帧。
- 任务按钮反映实际面板状态，第二次点击收起。面板打开时点击文字入口会显示文字卡，草稿保留。
- 语音规划同时选择已安装的立绘表情；沿用 Sol medium，依据近期上下文，保留中文显示与日语朗读。
  语音合成后、播放前应用该段表情；取消、切换会话后旧结果无效。纯文字角色也能使用表情。
- 本机角色包安装 11 张同组半身表情，并以设定图中的红白蓝像素飞船发饰作为托盘图标。
  图标和立绘只存于本地角色目录；仓库仅包含通用渲染和校验代码。

验证：TypeScript、Biome、构建，以及两个独立 PostgreSQL 库、真实 QML/D-Bus 回归通过，**155 项通过、13 项可选跳过**。
原生 Wayland 检查确认任务／记忆／桌面开关时画布保持 940 × 720、角色位置与 Image 实例不变，文字卡不重叠。
真实优化模型的展开／沉浸／辅助面板截图和 390 px 窄屏布局已检查。
真实 Sol 对安慰、解释、庆祝三组人工构造语境返回对应表情与日语台词；没有使用正式聊天历史进行测试，没有启用麦克风或外放。

常驻授权与主动观察开关随后改用统一的 `ToggleSwitch`：滑块左右移动、开启底色固定为薄荷绿，窗口失焦不改变状态颜色；仅不可操作时降低透明度。
